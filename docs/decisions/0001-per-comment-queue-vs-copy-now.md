# Per-comment choice between Comment Queue and Copy Now

Submitting a comment asks the reviewer for one of two actions on the spot: "Add to Queue" saves it into the [[Comment Queue]] for a later bulk hand-off, "Copy Now" copies just that comment to the clipboard and never saves it. The choice is per comment so that one review can mix one-off copies and queued comments without changing a setting first.

## Considered Options

- **A global mode toggle in Settings**, applying to every comment for the session or project: rejected — mixing the two within one review would mean changing a setting mid-review.
