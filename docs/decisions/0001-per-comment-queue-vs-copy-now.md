# Per-comment choice between Comment Queue and Copy Now

When submitting a comment, the reviewer picks one of two actions on the spot — "Add to Queue" (saves it into the [[Comment Queue]] for a later bulk hand-off) or "Copy Now" (copies just that comment to the clipboard immediately, never saved). We considered a global mode toggle (e.g. in Settings) that would apply to every comment for the session/project instead, but chose per-comment control so a reviewer can mix one-off copies and queued comments within the same review without changing a setting first.
